# Timestamp-grounded teaching

## Retrieve before explaining

1. Find source ID, playlist position, transcript revision, language, availability,
   coverage flags, and visual limitations in `sources/manifest.json`.
2. Search chunks/index for the concept and synonyms. Search across sources when
   appropriate. Keyword absence does not prove a topic is absent.
3. Read matching raw cues plus adjacent context. Verify definitions, negation,
   speaker, units, and prerequisite context. Narrow to the actual supporting cues.
4. Cite supporting ranges in each source's own timeline. Never add preceding
   playlist durations to a video playback timestamp.
5. If evidence is unavailable or contradictory, identify the gap or cite both
   versions. Request missing material or label supplementary teaching explicitly.

Citation format (illustrative, not actual evidence):

`Video 03 — <title> [v03, 00:42:10–00:46:35], cues c00301–c00324,
transcript <hash>; <playback link at 2530 seconds>`.

For a verified YouTube video ID use
`https://www.youtube.com/watch?v=<id>&t=<integer-start-seconds>s`.
Always show the end time in the label; the link sets only the start. Use another
platform's time syntax only if verified; otherwise provide original URL plus a
manual seek range. For local media use relative path plus range. Approximate
speech alignment times must be labeled approximate with their method recorded.

## Watch plan

| Order | Video / ID | Watch range | Purpose/objective | Prerequisite | Required? |
|---|---|---|---|---|---|

Use complete concept boundaries, not arbitrary tiny snippets. Keep separate
intervals when a concept is revisited. Calculate unique time as the union of
selected ranges per source; don't count overlaps twice. Distinguish viewing time
from estimated practice time. End with a concrete task to attempt after watching.
Attach the relevant watch reference directly to each explanation or worked example.

## Evidence limits

Untimed text supports line-based citations, not verified playback times. Request
timed captions or authorized media to align; keep this source pending while using
available evidence. Preserve ASR originals and record corrections separately.
Timestamp gaps can be silence or omitted speech: flag them for inspection without
claiming all gaps are missing teaching. Captions alone cannot prove on-screen
visual content or that the assistant/learner watched the video.
